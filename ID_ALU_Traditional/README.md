# CPU C - ID_ALU_Traditional

Standalone CPU C RTL snapshot from the Vivado project:
project_rtl_mach_c.

- rtl/: active SystemVerilog/Verilog design modules
- tb/: Vivado SystemVerilog testbenches
- docs/: project notes

The RTL is copied from the local CPU C source directories.
CPU A (EX_ALU33) and CPU B (EX_ALU_Traditional) are separate
directories and are not modified by this publication script.

The testbenches are included as source files; server regression
results must be recorded separately after running them on the server.
